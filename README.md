# GNNHub
GNNHub aims to determine central hubs within a large protein-protein interaction network to further prioritize further downstream analyses.

# How to run the code:
1. Download the File (Supplementary Table S1)
2. Divide and save exp.csv, ppi.csv, and pat.csv into separate CSV files
   - The exp.csv file should contain gene expression data
   - The ppi.csv file should contain protein-protein interaction data from the STRING database
   - The pat.csv file should contain the KEGG or other pathway genes list
   # Follow the file format from Supplementary Table S1.
4. Run on the local environment using the code
